A FEW THINGS TO KNOW

开打前，
你可能想知道。

遇到问题？到 GitHub 反馈 ↗
这是 CAPCOM 的官方工具吗？+

SF6 Tracker 是独立开发的非官方工具，与 CAPCOM 无隶属关系。《街头霸王 6》及相关游戏素材的权利归各自权利人所有。

需要登录吗？Cookie 会上传到这个网站吗？+

查询官网数据需要在应用内导入 Buckler 登录 Cookie。这个网站只负责介绍和下载，不收集 Cookie。Cookie 属于登录凭证，请不要分享；应用默认按会话保存，主动选择“记住登录”后会写入本机未加密存储。

这个网站能直接查战绩吗？+

这里是 SF6 Tracker 的介绍与下载入口。下载桌面应用后，在自己的电脑上登录、查询和整理记录。网站上的截图与视频只是产品展示。

可以找回全部历史对局吗？+

官网只提供近期对局窗口。本地历史从首次保存起积累，并按玩家归档；无法补回官网已不再提供的旧对局。已经保存的记录可以离线查看。
